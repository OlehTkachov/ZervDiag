# История изменений

## 0.6.0 — Generic Guided Diagnostics

- Добавлен Guided workflow REFERENCE/ACTION для неизвестной машины.
- Добавлены несколько повторов, repeatability и transparent confidence score.
- Добавлен temporal analyzer для bit/byte transitions, ramp, return и timeline.
- Добавлены quality checks и защита от пересекающихся/пустых окон и разных buses.
- Добавлены открытые `.craneprofile` и `.canexperiment` JSON-документы.
- Добавлены статусы знания и evidence без автоматического CONFIRMED.
- SOOSAN оставлен только regression fixture; live CAN и Tx отсутствуют.

## 0.4.1-test — 27.08.2026

- Исправлен дымовой тест экспорта стендового CSV: теперь он проверяет значения
  полей, а не необязательное наличие кавычек вокруг одиночного перехода бита.
- Расчёт сравнения состояний и формат отчёта не изменялись.

## 0.4.0-test — 26.08.2026

- Добавлен отдельный экран `Стендовые испытания`.
- Реализована последовательная запись пары `норма → одно изменение`.
- Каждое состояние формируется по 20, 30, 40 или 50 полным циклам ОНК-160.
- Для каждого байта вычисляются устойчивое значение, процент совпадения и наличие пакета.
- Добавлено побитовое сравнение с маской XOR и переходами `бит: было→стало`.
- Изменения контрольной суммы отмечаются отдельно от информационных байтов.
- Добавлена защита от пропуска метаданных испытания и неравных выборок.
- Добавлено сохранение отчёта стендового испытания в CSV для Excel.
- README преобразован в подробный операторский регламент с контрольными списками.
- README и схема адаптера автоматически включаются в папку публикации; для EXE создаётся SHA-256.

## 0.3.0-test — 26.08.2026

- Создана отдельная тестовая редакция только для ОНК-160С-02 / КС-55727.
- Удалена зависимость исполняемой программы от PEAK/PCAN-Basic.
- Убраны обычные CAN- и HC4900-профили; ОНК-160 выбирается при запуске.
- Оставлены реальный COM-драйвер и виртуальный ОНК-160 для проверки интерфейса.
- Публикация Windows x64 стала автономной (`self-contained`): на целевом ПК не нужен .NET Runtime.
- Имя программы изменено на `CraneCAN.ONK160.Test.exe`.

## 0.2.1 — 26.08.2026

- Добавлен резервный поиск COM-портов в реестре Windows.
- Поле `Канал/COM` стало редактируемым для ручного ввода, например `COM4`.
- Ручной COM-порт открывается напрямую, даже если автоматический список пуст.
- Добавлены отдельные сообщения для занятого порта и отсутствующего VCP-драйвера.

## 0.2.0 — 25.08.2026

- Добавлен пассивный драйвер ОНК-160 через COM-порт: 38 400 бит/с, 8E1.
- Добавлена сборка пакетов CA/E5/E6/E8/F7 и сохранение неизвестных байтов.
- Добавлена проверка контрольной суммы пакетов.
- Добавлена живая расшифровка E31, E83 и предварительного эталона E55.
- Добавлен виртуальный ОНК-160 для проверки интерфейса без адаптера.
- CSV расширен полями протокола и результата проверки суммы; старый CSV 0.1 читается.
- Добавлена инструкция пассивного адаптера TJA1050 → USB-UART.

## 0.1.0 — 25.08.2026

- Первый пассивный MVP для PEAK PCAN-USB и Classical CAN.
