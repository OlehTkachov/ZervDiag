# SOOSAN JK1200A — полевой CAN-захват

## Роль инструментов

На полигоне PCAN-View остаётся эталонным регистратором. CraneCAN используется параллельно для импорта `.trc`, статистики и сравнения состояний. Испытание не должно зависеть от готовности нового UI CraneCAN: первичный артефакт всегда сохраняется в формате PCAN-View `.trc`.

## Настройки PCAN-View

- 250 kbit/s.
- CAN 2.0.
- Listen-only.
- Принимать Standard и Extended кадры.
- Фильтры при записи полностью открыты.
- Передача кадров запрещена.
- Дополнительную терминацию не подключать.

## Основная точка для контрольного теста

HCH2 / HCL2 контроллера HYDAC TTC60. Подключение через штатный переходник в разрыв так, чтобы оба штатных устройства оставались соединёнными, а PCAN был подключён параллельно.

## Контрольный тест автоматического телескопирования

1. Подключить PCAN к HCH2/HCL2 и проверить, что штатная сеть полностью собрана.
2. Запустить двигатель.
3. Установить 1150–1200 об/мин.
4. Дождаться окончания зарядки LPU и готовности системы.
5. Запустить новую Trace-запись с открытыми фильтрами Standard/Extended.
6. Задать длину стрелы больше фактической и выждать примерно 10 секунд.
7. Отклонить джойстик на EXTEND на 2–3 секунды. Если движение начнётся — сразу вернуть джойстик в нейтраль.
8. После возврата в нейтраль записывать ещё не менее 5 секунд.
9. Сохранить исходный файл как `JK1200A_HCH2_engine_1200rpm.trc`.
10. Файл не редактировать. Для любых последующих обработок делать копию.

## Желательная дополнительная пара для Experiment Comparator

Для автоматического поиска изменившихся битов лучше иметь два отдельных окна/файла при одинаковых условиях:

- `REFERENCE`: система готова, джойстик в нейтрали, 10–20 с.
- `ACTION_EXTEND`: те же условия, затем одно воздействие — только джойстик EXTEND, 2–3 с, затем нейтраль.

Если удобно, можно записать это одним длинным `.trc`: CraneCAN позже будет уметь выбирать временные интервалы внутри одной трассы.

## Что проверяем в HCH2

Приоритетные признаки по уже расшифрованным данным:

- `0x0CF00400` — обороты двигателя.
- `0x0CFF5121` — состояние LPU / Y05.
- `0x188C0121` — AUTO/LMB.
- `0x0CFF5821` — restricted modes, особенно RM05.
- `0x0CFF1421` — обработанный джойстик EXTEND.
- `0x0CFF3621` — переход IDLE ↔ PICKUP.
- `0x0CFF2121` — выбранная секция/позиция/направление.
- `0x0CFF8411` — рассчитанное расстояние до остановки.
- `0x18720121` — уставка клапанов телескопического цилиндра.
- `0x0CFF5321` — фактический ток Y060/Y061.

Ключевая развилка: если при работающем двигателе, готовой LPU и отсутствии RM05 появляется Y060 — искать дальше силовую электрическую/гидравлическую цепь. Если все разрешения выполнены, а Y060 остаётся нулём — искать внутреннее условие TTC60/конфигурации.
