# Analog Calibration / Physical Correlation

## Назначение

Этап связывает уже найденное raw CAN-поле с реальными физическими измерениями. Типичный полевой пример для телескопической стрелы:

```text
raw 1000 = 12.5 m
raw 1300 = 14.0 m
raw 1700 = 16.0 m
```

CraneCAN рассчитывает линейную модель:

```text
physical = raw * Scale + Offset
```

и показывает Scale, Offset, R², RMSE, максимальную абсолютную ошибку и ошибку как процент от измеренного физического диапазона.

## Рабочий процесс

1. Выполнить Guided REFERENCE/ACTION и открыть `Аналоговые сигналы…`.
2. Добавить подходящий raw-кандидат в Machine Profile. На этом этапе он остаётся `CANDIDATE`, `Scale=1`, `Offset=0`, `Unit` пустой.
3. Нажать `Калибровка raw…`.
4. Выбрать нужный Machine Profile signal.
5. Ввести инженерную единицу (`m`, `deg`, `bar`, `MPa`, `%` и т. п.). Unit всегда задаёт инженер; программа не пытается угадать физический смысл по CAN.
6. Ввести минимум две строки `raw = physical`.
7. Нажать `Рассчитать` и проверить residuals/ошибку.
8. Только после явного подтверждения применить Scale/Offset/Unit к текущему Machine Profile.
9. Сохранить `.craneprofile` обычной кнопкой `Сохранить…`.

Десятичная точка и запятая принимаются. Поддерживается также разделитель `;`. Строки с `#` используются как комментарии.

## Две точки и проверка линейности

Две точки достаточны, чтобы однозначно вычислить прямую. Поэтому для двух точек результат помечается `TwoPointOnly`: Scale/Offset можно применить после явного подтверждения, но CraneCAN не сообщает, что линейность датчика проверена.

Для реальной проверки рекомендуется минимум три точки, распределённые по рабочему диапазону. Например, для датчика длины полезнее измерить полностью втянутую, промежуточную и более выдвинутую стрелу, чем три точки, расположенные рядом.

## Классификация качества

Для 3+ точек текущие консервативные критерии:

- `EXCELLENT`: R² ≥ 0.999, RMSE ≤ 0.5% физического диапазона и максимальная ошибка ≤ 1.0%;
- `GOOD`: R² ≥ 0.995, RMSE ≤ 1.5% диапазона и максимальная ошибка ≤ 2.5%;
- `POOR`: критерии выше не выполнены.

`POOR` нельзя записать в Machine Profile из этого инструмента. Нужно повторить измерения, проверить raw-поле, битовую разметку, signedness, механическое положение и добавить точки по диапазону.

Эти пороги являются диагностическими критериями CraneCAN, а не паспортными допусками конкретного датчика/крана.

## Что сохраняется в Machine Profile

После подтверждения изменяются только:

- `Scale`;
- `Offset`;
- `Unit`;
- `UpdatedAt`;
- добавляется `SignalEvidence` вида `PhysicalOutputCheck`.

CAN ID, Standard/Extended, byte/bit/length, endian, signedness, имя и Signal ID не изменяются.

Существующий `Confidence` сохраняется. В частности, `CANDIDATE` не становится автоматически `PROBABLE` или `CONFIRMED` только потому, что к нему рассчитали физическую шкалу.

Evidence содержит сами пары raw→physical и метрики аппроксимации, но не содержит абсолютных путей к локальным TRC.

## Signed raw

Калибровка работает с числом, которое инженер вводит как raw до Scale/Offset. Если Machine Profile signal отмечен `IsSigned=true`, нужно вводить уже декодированное знаковое raw-значение, например `-120 = -3.0`.

Инструмент не меняет signedness автоматически.

## Безопасность

Analog Calibration работает только с уже полученными данными и Machine Profile. Она не отправляет CAN-сообщения, не записывает параметры в ECU и не выполняет reset/calibration в контроллере машины.

Физическая корреляция подтверждает математическую связь выбранного raw-поля с введёнными измерениями. Она сама по себе не доказывает, какой ECU является источником неисправности, и не заменяет независимую проверку датчика/механики.

## SOOSAN / HYDAC

Для задачи поиска длины стрелы этот инструмент позволяет разделить два этапа:

1. найти raw-поле, которое повторяемо меняется при телескопировании;
2. независимо измерить фактическую длину/положение в нескольких точках и проверить, соответствует ли raw линейной физической шкале.

Это полезно для диагностики несоответствия показаний на экране реальному положению, но не является способом обхода сервисного пароля или отправки команды `Reset HYDAC length sensor`.
