# Live Guided Diagnostics — безопасный операторский регламент

## 1. Назначение

Live Guided Diagnostics наблюдает CAN во время одного заранее понятного
физического действия. Программа не передаёт CAN-команды. Оператор принимает
решение, допустимо ли действие в текущем состоянии машины, и в любой момент
может выбрать `ABORT / STOP`.

## 2. Обязательная проверка до подключения к машине

- Запустить комплектный `samples\live_guided_demo.trc` через Replay.
- Получить состояние `COMPLETED`, `VALID` и кандидаты `0x18F`.
- Сохранить и повторно открыть `.canexperiment`.
- Убедиться, что на ноутбуке отключены сон и автоматическая перезагрузка.
- Проверить свободное место: сырой CAN пишется непрерывно.
- Для PCAN установить официальный PEAK Device Driver x64.
- Иметь PCAN-View как основной и независимо проверенный регистратор.

Если Replay не проходит, к машине эту сборку не подключать.

## 3. Физическое подключение

1. Выбрать известную диагностическую точку CAN-H/CAN-L/GND.
2. Подключить PCAN параллельно, не разрывая штатную сеть.
3. Не добавлять 120 Ом к уже терминированной работающей шине.
4. Запретить передачу в PCAN-View и использовать Listen-only.
5. Выбрать тот же Classical CAN bitrate в CraneCAN.
6. Нажать **Найти каналы** и **ПОДКЛЮЧИТЬ**.
7. Не начинать опыт без двух одновременных признаков:
   `CONNECTED` и `LISTEN ONLY`.

Драйвер CraneCAN сначала задаёт Listen-only как preset-параметр, открывает
канал, затем читает параметр обратно. Несовпадение закрывает канал. В native
обёртке отсутствует импорт функции записи PCAN.

## 4. Один опыт

По умолчанию используются этапы:

| Этап | Длительность | Действие оператора |
|---|---:|---|
| REFERENCE | 5 s | Ничего не трогать. |
| Waiting | 3 s | Приготовиться, но действие не начинать. |
| ACTION | 10 s | Выполнить только показанное действие. |
| POST | 5 s | STOP, вернуть орган в нейтраль, ничего не трогать. |
| ANALYZING | автоматически | Дождаться результата. |

Длительности можно изменить до старта. В одном опыте меняется только один
физический фактор. Условия, обороты, режим и нагрузки между повторами должны
оставаться одинаковыми.

`INVALID` или `ABORTED` не формирует уверенный список кандидатов. Причину
следует устранить и опыт повторить; неполные данные не использовать как
evidence.

## 5. Повторы и интерпретация

Рекомендуется три одинаковых повтора. CraneCAN агрегирует их существующим
Generic Analyzer и показывает repeatability. Высокий score означает сильную
наблюдаемую корреляцию, но не доказывает назначение внутри ECU.

Корректная формулировка:

> `0x181 DATA[3] strongly correlates with BOOM_UP`.

Некорректная формулировка без независимого подтверждения:

> `0x181 DATA[3] точно является джойстиком подъёма`.

## 6. Аварийные случаи

| Событие | Действие |
|---|---|
| Отключён PCAN | STOP, опыт становится INVALID; переподключить адаптер. |
| Нет кадров | Проверить точку, питание, bitrate и CAN-H/CAN-L; не анализировать пустой опыт. |
| BUS-OFF/ошибки | Прекратить Live-тест, сохранить PCAN-View TRC и проверить физическую шину. |
| Потери кадров | Пометить опыт непригодным и снизить нагрузку/проверить USB. |
| Неверное действие | Нажать ABORT, вернуть орган в нейтраль, начать новый повтор. |
| Закрытие программы | Активный опыт получает ABORT; драйвер и файл закрываются безопасно. |
| PCAN-View конфликтует | Оставить PCAN-View главным регистратором; анализировать его TRC offline. |

## 7. Сохраняемые файлы

`Документы\CraneCAN\LiveCaptures` содержит:

- полный сырой TRC подключения;
- отдельный TRC-сегмент каждого валидного опыта;
- после ручного сохранения — `.canexperiment` в выбранном месте.

`.canexperiment` — открытый JSON. Он хранит источник, канал, bitrate,
подтверждение Listen-only, абсолютные границы всех этапов, инструкцию,
счётчики Standard/Extended/lost/error, warnings и снимки кандидатов. Большие
TRC остаются отдельными файлами, поэтому при переносе проекта копировать нужно
и `.canexperiment`, и связанные TRC.

## 8. SOOSAN JK1200A

Live Guided не обязателен для ближайшего полигона. Главным регистратором
остаётся PCAN-View: `250 kbit/s`, Classical CAN 2.0, Listen-only, Standard +
Extended, открытые фильтры, передача запрещена, дополнительная терминация
выключена. Сначала сохранить обычный `JK1200A_HCH2_engine_1200rpm.trc`, затем
анализировать его offline. Live проверять позже в цеху после успешного Replay.
