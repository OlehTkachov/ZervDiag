# Incident Signal Builder — CraneCAN 0.7

## Назначение

Signal Builder позволяет превратить **выбранное наблюдаемое изменение DATA[n]**
из `Incident Event Chain` в экспериментальный сигнал текущего Machine Profile.

Он не выполняет CAN Tx и не меняет параметры контроллера.

## Почему только DATA[n]

События `ID появился`, `ID исчез` и `DLC изменился` описывают сообщение целиком
и не дают достаточного основания автоматически создавать конкретное битовое
поле. Поэтому кнопка Signal Builder активна только для шага `байт изменился`.

Пользователь задаёт:

- название сигнала;
- StartByte;
- StartBit;
- BitLength;
- byte order;
- signed/unsigned;
- scale;
- offset;
- unit;
- заметки.

Выбранное битовое поле обязано физически пересекать тот `DATA[n]`, изменение
которого послужило evidence.

## Статус знания

Новый сигнал всегда создаётся как `CANDIDATE`.

Один incident не переводит сигнал автоматически в `PROBABLE` или `CONFIRMED`.
Для повышения статуса нужны дополнительные evidence: повторяемые эксперименты,
документация, схема, измерение или явное подтверждение пользователя.

В Machine Profile сохраняется evidence типа `IncidentCapture` с:

- временем изменения относительно marker;
- baseline → observed;
- приоритетом Incident First Changes;
- уникальной ссылкой на incident-marker/ID/DATA.

Повторное добавление того же самого incident не дублирует evidence.
Новый incident для того же битового поля добавляет ещё один evidence.

Если выбранное поле уже существует в Machine Profile, его имя, engineering
параметры и текущий статус не перезаписываются: добавляется только новое
incident evidence. В частности, существующий `CONFIRMED` сигнал не может быть
понижен до `CANDIDATE` этим инструментом.

## Рабочий порядок

1. открыть `.canincident`;
2. выполнить `Анализ изменений у отметки`;
3. открыть `Цепочка событий`;
4. выбрать строку `байт изменился`;
5. нажать `Добавить DATA-шаг в профиль…`;
6. задать физически осмысленное имя/битовое поле;
7. сохранить `.craneprofile` штатной кнопкой сохранения профиля.

Signal Builder фиксирует инженерную гипотезу и её provenance, но не объявляет
неизвестный CAN-байт доказанным джойстиком, клапаном или датчиком.
