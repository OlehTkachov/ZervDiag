# Подготовка пассивного захвата ОНК-160С-02

Основной пошаговый регламент находится в корневом `README.md`. Этот файл
содержит краткую памятку по электрической части.

## Оборудование

1. Ноутбук с Windows 10/11 x64.
2. TJA1050 в аппаратном Silent mode.
3. Изолированный USB-UART с подходящим логическим уровнем RX.
4. Ответная часть штатного разъёма либо безопасный диагностический переходник.
5. Мультиметр.

## Разъём ОНК-160С-02 на исследованном стенде

- контакт 4: GND;
- контакт 5: экран;
- контакт 6: CAN-H;
- контакт 7: CAN-L;
- полностью собранная обесточенная линия: `60±5 Ом`;
- CAN-H и CAN-L относительно GND в покое: `2,5±0,2 В`;
- обмен: собственный UART через TJA1050, не CAN 2.0;
- параметры: `38 400 бит/с, 8E1, LSB first`;
- приём: TJA1050 Silent → RX USB-UART → COM-порт Windows.

Терминаторы находятся в БОИ и датчике вылета. Дополнительный терминатор при
сопротивлении линии около 60 Ом не устанавливать. Полная схема приёмника
приведена в `ONK160_UART_ADAPTER.md`.

## Последовательность

1. Обесточить стенд.
2. Проверить сопротивление CAN-H/CAN-L.
3. Проверить Silent mode и физическое отсутствие соединения USB-UART TX.
4. Подключить CAN-H, CAN-L и GND к входной стороне приёмника.
5. Подключить USB-UART к компьютеру и проверить появление COM-порта.
6. Включить стенд.
7. Запустить программу и проверить пакеты с корректной контрольной суммой.
8. Для каждого опыта записать норму, изменить только один фактор, записать
   второе состояние и сохранить оба CSV.

Передача, воспроизведение, имитация узлов и запись памяти БОИ запрещены.
